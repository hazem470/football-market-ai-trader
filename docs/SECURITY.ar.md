اقرأ الصفحة دي كاملة قبل ما تحط أي فلوس قريب من البرنامج ده.

## القواعد المطلقة

1. **لا تشارك «Seed Phrase» (عبارة الاسترداد) مع أي أحد. أبدًا.** لا مع هذا المشروع، ولا مع أي
   مطوّر، ولا في Issue على GitHub، ولا على تليجرام أو Discord، ولا في لوحة التحكم، ولا في أي قاعدة
   بيانات سحابية. عبارة الاسترداد تتحكم في محفظتك بالكامل، وتسريبها لا رجعة فيه.
2. **لا ترفع مفتاحًا خاصًا على Git.** ملف `.env` مذكور في `.gitignore` — سيبها كده. الـ CI بيفشل
   البناء لو اتلصق أي نص شكله مفتاح.
3. **لا تستخدم محفظتك الأساسية في التداول الآلي.** استخدم **محفظة تداول منفصلة** مموّلة بالمبلغ
   اللي تتحمل خسارته فقط.
4. **لا ترسل أي أسرار على تليجرام.** طبقة الإشعارات أصلًا لا تستطيع إظهارها — كل سطر سجل بيمرّ
   على فلتر تنقيح قبل الكتابة.
5. **التداول الحقيقي معطّل افتراضيًا ويحتاج ثلاث خطوات منفصلة لتفعيله.** سيبها كده لحد ما
   تجرّب shadow و paper لفترة معقولة.

## اللي البرنامج بيرفض يعمله

* **يرفض يقبل Seed Phrase.** `assert_not_a_mnemonic` بيكتشف أي نص شكله عبارة استرداد ويرفع
  `SeedPhraseRejected` برسالة واضحة. ده بيمشي على `.env` وعلى مخزن مفاتيح النظام وعلى أي مدخل
  برمجي.
* **يرفض يخزّن مفتاح جوّه الريبو.** `assert_file_not_committable` بيمنع قراءة سر محفظة من أي مسار
  جوه الشجرة.
* **يرفض يطبع أي سر.** `Secrets` و `WalletConfig` معطّل فيهم `repr` على مستوى الـ dataclass، فالمفتاح
  ما يقدرش يظهر في traceback ولا سجل ولا `print()`.
* **يرفض يبعت سر لأي مكان.** فلتر التنقيح بيمشي على **كل** سجل قبل ما يوصل لأي مخرج.

## فين بتتخزن بيانات الدخول

| السر | المكان | الحماية |
|---|---|---|
| مفتاح محفظة التداول المنفصلة | `.env` أو مخزن مفاتيح النظام | مستثنى من Git، مرفوض لو شكله Seed Phrase، منقّح في السجلات |
| مفاتيح Polymarket API | `.env` | نفس الحماية، وتقدر تسيبها فاضية وتتولّد تلقائيًا |
| مفتاح مزوّد الذكاء الاصطناعي | `.env` | اختياري تمامًا |
| توكن بوت تليجرام | `.env` | اختياري، وبوت بتاعك أنت |
| كلمة سر الداشبورد | `.env` | فقط لو نشرت اللوحة على الإنترنت |

**بديل أنضف من `.env`** — استخدم مخزن مفاتيح النظام:

```bash
python -c "import keyring; keyring.set_password('football-market-ai-trader','polymarket_private_key','0x...')"
```

وسيب `POLYMARKET_PRIVATE_KEY` فاضي في `.env` — البرنامج هيلاقيه في المخزن.

## إعداد المحفظة — الطريقة الصح

```
أنت
  ← محفظة تداول منفصلة        (جديدة، ومش محفظتك الأساسية)
  ← مصادقة Polymarket الرسمية  (المكتبة بتوقّع؛ المفتاح ما يسيبش جهازك)
  ← Polymarket
```

1. اعمل محفظة **جديدة** مخصصة للبوت ده فقط.
2. موّلها بـ USDC على Polygon — الحد الأدنى اللي محتاجه، مش مدخراتك.
3. اربطها بحساب Polymarket واضبط الصلاحيات (allowances).
4. انقل **مفتاح المحفظة دي بس** إلى `.env` المحلي أو مخزن المفاتيح.
5. لا تعيد استخدام المفتاح في أي بوت أو موقع أو جهاز تاني.

### نوع التوقيع

| طريقة دخولك | `POLYMARKET_SIGNATURE_TYPE` | ملاحظات |
|---|---|---|
| محفظة مباشرة (EOA) | `0` | التداول مباشرة من المحفظة |
| إيميل Polymarket / Magic | `1` | يحتاج `POLYMARKET_FUNDER_ADDRESS` (العنوان الوسيط) |
| MetaMask / Rabby / Coinbase | `2` | يحتاج `POLYMARKET_FUNDER_ADDRESS` (العنوان الوسيط) |

لو غلطت هنا هتشوف رسالة `wallet/funder mismatch` أو رصيد صفر.

## التنقيح (Redaction)

كل سجل بيمرّ على أنماط التنقيح دي قبل الكتابة:

| النمط | مثال |
|---|---|
| نص 64 حرف hex | مفتاح خاص خام |
| 12 كلمة أو أكثر | عبارة استرداد |
| `<أرقام>:<توكن>` | توكن بوت تليجرام |
| `eyJ…` بثلاث مقاطع | JWT |
| `Bearer …` / `api_key=…` | ترويسة مصادقة أو مفتاح |

وكمان بيتشيّل المفاتيح الحساسة من أي بيانات منظمة: `private_key`, `api_secret`, `api_key`,
`passphrase`, `bot_token`, `seed`, `mnemonic`, `authorization`, `password`, `token`.

وفيه كمان **فحص أسرار على مستوى الريبو** بيمشي في `check` وفي الـ CI
(`scripts/scan_secrets.py`): مفاتيح AWS، توكنات GitHub، Slack، Google، OpenAI، تليجرام، وأي مفتاح
خاص خام.

## نموذج التهديد

### داخل النطاق

1. **تسريب بيانات الدخول** عبر السجلات أو الاستثناءات أو القاموس أو ملف مرفوع على Git.
2. **إرسال أمر غير مصرّح به** — أي مسار يبعت أمر من غير ما يعدّي كل البوابات ومحرك المخاطرة.
3. **تجاوز حدود المخاطرة** — حجم، أو تعرض، أو حد خسارة، أو ارتباط، يقدر يتحايل عليه سوق أو إشارة.
4. **أوامر مكرّرة** — إعادة محاولة تعمل تنفيذ تاني لنفس الإشارة.
5. **تداول صامت على بيانات سيئة** — مدخل ناقص أو قديم يتحوّل لقيمة مُختلقة بدل ما يترفض.

### خارج النطاق

* اختراق جهازك أو محفظة المتصفح بتاعتك.
* بنية Polymarket نفسها أو شروطها أو استمرار خدمتها.
* الامتثال القانوني في بلدك — ده مسؤوليتك أنت.
* خسائر من استراتيجية متنفّذة صح لكنها ببساطة غير مربحة.

### إزاي كل خطر متعالَج

| الخطر | العلاج |
|---|---|
| تسريب بيانات | فلتر تنقيح على كل سجل + `repr` معطّل + فحص أسرار في `check` والـ CI + `.env` مستثنى |
| أوامر غير مصرّح بها | ثلاث بوابات (متغيّر بيئة + عبارة تأكيد + فحص مسبق) ومفروضة جوه الكود نفسه |
| تجاوز حدود المخاطرة | `RiskEngine` هو المسار الوحيد لتنفيذ الأوامر، والحجم بيتقيّد بعد Kelly |
| أوامر مكرّرة | معرّف أمر مشتق من معرّف الإشارة + فحص المراكز والأوامر المفتوحة، **بدون** إعادة محاولة عمياء |
| تداول على بيانات سيئة | فحص وتحقق + فرع `INSUFFICIENT_DATA` صريح؛ رقم النموذج بيترمى لو ميزة مطلوبة ناقصة |

## توصيات التشغيل

* شغّل `python -m app.cli check` قبل كل جلسة — فيه فحص الأسرار.
* سيب `RISK_MAX_TRADE` صغير (الافتراضي 10 من رأس مال 500) واضبط `RISK_MAX_DAILY_LOSS`.
* سيب الزر الطارئ شغال، وجرّبه بـ `python -m app.cli stop` وتأكد إن الأوامر الجديدة اتمنعت.
* شغّل shadow ثم paper لمدة كافية تشوف فيها رفض منطقي ومفيش تفعيل عشوائي للزر.
* شغّل live على جهاز بتتحكم فيه فقط. أبدًا على جهاز مشترك.

## لو اتسرّب أي بيان دخول

اتعامل معاه كإنه اتسرّب فعلًا من اللحظة اللي سابت فيها جهازك.

1. **انقل الأموال** من محفظة التداول المنفصلة لعنوان آمن فورًا.
2. **ألغِ المفاتيح**: Polymarket → API keys؛ مزوّد الذكاء الاصطناعي → اعمل مفتاح جديد؛
   تليجرام → `/revoke` مع @BotFather.
3. **امسح السر** من `.env` (أو امسحه من مخزن المفاتيح)، واعمل محفظة جديدة لو المفتاح الخاص نفسه
   اتسرّب.
4. لو السر وصل لـ commit على Git: عدّل التاريخ (`git filter-repo`) واعمل force-push،
   **واعتبره مسرّبًا على أي حال** — بدّل الأول، ونضّف بعدين.
5. راجع باقي خدماتك لو كنت مستخدم نفس المفتاح في مكان تاني.

## مسح بيانات الدخول من جهازك

```bash
# 1) وقّف أي حاجة شغالة
python -m app.cli stop --reason "تبديل مفاتيح"

# 2) امسح القيم وسيب البنية
cp .env.example .env

# 3) أو احذف الملف بالكامل
rm .env

# 4) لو كنت مستخدم مخزن مفاتيح النظام
python -c "import keyring; keyring.delete_password('football-market-ai-trader','polymarket_private_key')"

# 5) تأكد إن مفيش حاجة سرّية فاضلة
python scripts/scan_secrets.py
python -m app.cli config      # كل سر لازم يظهر 'missing'
```

## إزاي توقف البرنامج / تعطّل التداول الحقيقي

**توقف التشغيل:** `Ctrl-C` في نافذة live، أو من نافذة تانية:

```bash
python -m app.cli stop --reason "إيقاف يدوي"
```

الزر بيمنع الأوامر الجديدة ويطلب إلغاء المعلّقة، بس **مش بيقفل المراكز المفتوحة** — القرار ده بتاعك.

**تعطيل التداول الحقيقي بشكل دائم:** في `.env` خلي:

```ini
TRADING_MODE=backtest
POLYMARKET_ALLOW_LIVE_TRADING=false
```

وضع live بقى غير قابل للوصول مهما استخدمت من أعلام على سطر الأوامر.

أموالك وبيانات دخولك ومحافظك. المطوّرون لا يملكون أي وصول لأموال أي مستخدم.
