# متداول أسواق كرة القدم بالذكاء الاصطناعي

<div dir="rtl">

**[English](README.md) · [دليل المستخدم الكامل](docs/USER_GUIDE.ar.md) · [English user guide](docs/USER_GUIDE.md)**

---

محرك بحث مفتوح المصدر **يكتشف أسواق كرة القدم الموجودة فعلًا على Polymarket**، ويقدّر احتمالاتها
من بيانات كرة القدم الحقيقية، ويقارنها بالسعر الذي يمكنك التنفيذ به فعلًا، ويطبّق حدود مخاطرة
صارمة، وبعدها فقط يقرر: **شراء / بيع / بدون تداول**.

يعمل بأربع طرق — **اختبار تاريخي (backtest)، وضع الظل (shadow)، التداول الوهمي (paper)، والتداول
الحقيقي (live)** — و**التداول الحقيقي معطّل افتراضيًا**. الريبو لا يحتوي على أي مفاتيح أو بيانات
دخول أو أموال خاصة بالمطوّر: كل مستخدم يجهّز حسابه وبياناته ومخاطرته بنفسه.

> **هذا ليس نصيحة مالية ولا يوجد أي ضمان للربح.** أسواق التنبؤ قادرة على خسارة المال وقد تخسره كله.
> اقرأ [docs/SECURITY.ar.md](docs/SECURITY.ar.md) قبل أن تفكر في التداول الحقيقي.

## الفكرة الأساسية

القاعدة الواحدة التي يلتزم بها المشروع كله:

```
سوق Polymarket
  ← ما هو القابل للتداول فعلًا؟
  ← ما البيانات المطلوبة؟
  ← هل يمكن الحصول عليها بشكل موثوق؟
  ← ما احتمال النموذج؟
  ← هل تمت معايرته؟
  ← ما سعر السوق القابل للتنفيذ فعلًا؟
  ← ما الربحية الواقعية بعد التكاليف وعدم اليقين؟
  ← هل المخاطرة مقبولة؟
  ← شراء / بيع / بدون تداول
```

**هذا الترتيب لا يُعكس أبدًا.** البرنامج لا يتنبأ بمباراة ثم يبحث عن سوق لتطبيق التوقع عليه. يبدأ
من السوق الموجود فعلًا، ويسأل ما البيانات التي يحتاجها، ويرفض
(`INSUFFICIENT_DATA` / `UNSUPPORTED` / `NO TRADE`) عندما تكون البيانات ناقصة أو قديمة أو غير
متاحة. **البيانات الناقصة لا تُختلق ولا تُقدَّر بقيمة متوسطة أبدًا.**

## التنزيل والتثبيت

### المتطلبات

| البرنامج | الحد الأدنى | من أين |
|---|---|---|
| Python | 3.10 أو أحدث (3.11 مستحسن) | [python.org/downloads](https://www.python.org/downloads/) |
| Git | أي نسخة حديثة | [git-scm.com](https://git-scm.com/downloads) |

> **ويندوز:** خلال تثبيت Python ضع علامة صح على **«Add Python to PATH»** وإلا لن تعمل الأوامر.

### الخطوات

```bash
# 1) نزّل المشروع
git clone https://github.com/hazem470/football-market-ai-trader.git
cd football-market-ai-trader

# 2) أنشئ بيئة معزولة (عشان ما تلخبطش نسخة بايثون عندك)
python -m venv .venv

# ويندوز:
.venv\Scripts\activate

# لينكس / ماك:
source .venv/bin/activate

# 3) ثبّت المكتبات
pip install -r requirements.txt

# 4) جهّز ملف الإعدادات والقاموس
python -m app.cli init

# 5) تأكد إن كل حاجة تمام
python -m app.cli check
```

بعد الأمر الخامس لازم تشوف آخر سطر:

```
READY - 0 critical failure(s), 0 warning(s)
```

**لا تحتاج أي مفاتيح API** للخطوات دي — مصادر البيانات المجانية كافية.

## التشغيل

### الترتيب الموصى به (لا تتخطاه)

```bash
# ايه الأسواق الموجودة على Polymarket دلوقتي فعلًا؟
python -m app.cli markets

# احسب الإشارات واطبعها (لا يشتري أي حاجة)
python -m app.cli signals --limit 25

# اختبار تاريخي للنموذج والاستراتيجية
python -m app.cli backtest --market-type MATCH_RESULT --league E0

# اضبط معايرة الاحتمالات على نتائج الاختبار التاريخي
python -m app.cli calibrate --market-type MATCH_RESULT --league E0

# وضع الظل: بيانات حقيقية، قرارات حقيقية، صفر أوردرات
python -m app.cli shadow --limit 25

# التداول الوهمي: بيانات حقيقية، رأس مال وهمي، حد مخاطرة حقيقي
python -m app.cli paper --limit 25 --iterations 4 --poll 120
```

### لوحة التحكم

```bash
streamlit run app/dashboard/streamlit_app.py
```

تفتح على `http://localhost:8501` وفيها 15 تبويب. **للقراءة فقط** — لا تستطيع تنفيذ أي أمر شراء.

## التداول الحقيقي (أموال حقيقية)

معطّل افتراضيًا، ويحتاج **الثلاثة معًا**:

```ini
# في ملف .env
TRADING_MODE=live
POLYMARKET_ALLOW_LIVE_TRADING=true
POLYMARKET_PRIVATE_KEY=0x...      # محفظة تداول منفصلة فقط
```

```bash
python -m app.cli live --limit 5 --confirm "I UNDERSTAND THE RISK" --i-understand-risk
```

لو أي فحص قبل التشغيل فشل، **لن يُرسل أي أمر**. اقرأ
[دليل المستخدم الكامل](docs/USER_GUIDE.ar.md) أولًا.

## الأمان في سطر واحد

**لا تُدخل أبدًا «Seed Phrase» (عبارة الاسترداد) في أي مكان.** البرنامج يرفضها بصوت عالٍ لأنه
مصمم على ذلك. استخدم فقط **مفتاح محفظة تداول منفصلة** مموّلة بالمبلغ الذي تتحمل خسارته.

## عائلات الأسواق المدعومة

| العائلة | الحالة |
|---|---|
| نتيجة المباراة (فوز/تعادل/خسارة) | ✅ مدعوم |
| مجموع الأهداف (أكثر/أقل) | ✅ مدعوم |
| تسجيل الفريقين | ✅ مدعوم |
| أهداف فريق واحد | ✅ مدعوم |
| الركنيات | ✅ مدعوم |
| أهداف لاعب / صناعة أهداف لاعب | ✅ مدعوم |
| تسديدات لاعب | ⚠️ يحتاج مصدر بيانات تسديدات |
| كروت / نتيجة شوط / النتيجة الدقيقة / أول من يسجل | ⛔ غير مدعوم — مفيش مصدر بيانات موثوق |

غير المدعوم يُرجع `UNSUPPORTED` بوضوح بدلًا من التخمين.
